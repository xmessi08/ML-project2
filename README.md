# Практическая работа № 2. Разведочный анализ данных (EDA)

## 1. Цель работы

Цель практической работы — провести разведочный анализ данных (Exploratory Data Analysis, EDA), изучить структуру датасета, определить типы признаков, исследовать распределения переменных, обнаружить пропущенные значения и потенциальные выбросы, а также изучить взаимосвязи между признаками.

В ходе работы необходимо использовать статистические методы и визуализацию для выявления особенностей и возможных проблем исходных данных.

Результаты анализа позволят определить, какие этапы предварительной обработки потребуются перед обучением модели машинного обучения.

## 2. Описание проекта

В данной работе исследуется датасет, содержащий медицинские показатели пациентов, используемые для анализа наличия заболеваний сердца.

Разведочный анализ проводится в Jupyter Notebook. Для обработки данных используются библиотеки Python, а для визуализации — Matplotlib и Seaborn.

В рамках работы выполняются:
- общий осмотр структуры датасета;
- классификация признаков по типам;
- проверка пропущенных значений;
- анализ распределений числовых признаков;
- поиск потенциальных выбросов;
- исследование частот категориальных признаков;
- анализ корреляций;
- оценка распределения целевой переменной;
- составление отчёта о проблемах данных.

## 3. Используемые технологии

В проекте используются следующие инструменты и библиотеки:

- **Python** — язык программирования для анализа данных.
- **Pandas** — загрузка, обработка и анализ табличных данных.
- **NumPy** — выполнение числовых операций.
- **Matplotlib** — построение графиков и диаграмм.
- **Seaborn** — визуализация распределений, корреляций и взаимосвязей между признаками.
- **Jupyter Notebook** — интерактивная среда для выполнения кода и документирования результатов.
- **Scikit-learn** — библиотека машинного обучения, которая может использоваться на последующих этапах проекта.
- **Git и GitHub** — контроль версий и хранение исходного кода проекта.

## 5. Описание датасета

Для анализа используется файл `heart_statlog_cleveland_hungary_final.csv`.

Датасет содержит медицинские характеристики пациентов, которые могут быть связаны с наличием заболевания сердца.

Основные признаки датасета:

| Признак | Описание | Предполагаемый тип |
|---|---|---|
| `age` | Возраст пациента | Числовой |
| `sex` | Пол пациента, закодированный числовым значением | Категориальный |
| `chest pain type` | Тип боли в груди | Категориальный |
| `resting bp s` | Артериальное давление в состоянии покоя | Числовой |
| `cholesterol` | Уровень холестерина | Числовой |
| `fasting blood sugar` | Показатель уровня сахара натощак, представленный бинарным значением | Категориальный |
| `resting ecg` | Результат электрокардиограммы в состоянии покоя | Категориальный |
| `max heart rate` | Максимальная частота сердечных сокращений | Числовой |
| `exercise angina` | Наличие стенокардии при физической нагрузке | Категориальный |
| `oldpeak` | Изменение сегмента ST при нагрузке относительно состояния покоя | Числовой |
| `ST slope` | Наклон сегмента ST при максимальной нагрузке | Категориальный |
| `target` | Целевая переменная: наличие или отсутствие заболевания сердца | Бинарная категориальная |

**Примечание:** типы признаков определяются по их смыслу, а не только по формату хранения в Pandas. Например, `sex` может иметь целочисленный тип, но представляет категорию, а не измеряемую числовую величину.

## 6. Этапы разведочного анализа данных

### 6.1. Загрузка данных и общий осмотр

На первом этапе датасет загружается в Pandas DataFrame.

Проводится проверка:
- количества строк и столбцов;
- названий столбцов;
- типов данных;
- количества непустых значений;
- первых строк таблицы.

Для этого используются методы `head()`, `info()`, `shape` и `dtypes`.

**Цель этапа:** понять структуру датасета и определить, какие признаки доступны для дальнейшего анализа.

### 6.2. Проверка пропущенных значений

Для каждого столбца определяется количество отсутствующих значений.

Проверка необходима, чтобы выявить признаки, которые могут потребовать дополнительной обработки.

Если пропуски обнаружены, на следующем этапе необходимо выбрать подходящий способ обработки с учётом типа признака и характера отсутствующих данных.

Если пропущенных значений нет, это также фиксируется в результатах анализа.

### 6.3. Классификация признаков

Признаки разделяются на следующие группы:

- **Числовые:** возраст, артериальное давление, уровень холестерина, максимальная частота сердечных сокращений и `oldpeak`.
- **Категориальные:** пол, тип боли в груди, результаты ЭКГ, стенокардия при нагрузке и наклон сегмента ST.
- **Целевая переменная:** `target`, используемая для обозначения класса пациента.

Такая классификация позволяет выбрать подходящие методы статистического анализа и визуализации для каждого признака.

### 6.4. Анализ распределений числовых признаков

Для числовых признаков строятся гистограммы распределения.

Гистограммы позволяют:
- определить диапазоны наиболее часто встречающихся значений;
- оценить симметричность распределения;
- обнаружить асимметрию;
- заметить необычные значения;
- определить возможную необходимость преобразования признаков.

Каждый график должен иметь заголовок, подписи осей и краткий текстовый вывод.

### 6.5. Поиск потенциальных выбросов

Для анализа выбросов строятся диаграммы размаха (boxplot).

В первую очередь исследуются числовые признаки, такие как `age`, `resting bp s`, `cholesterol`, `max heart rate` и `oldpeak`.

На boxplot можно обнаружить значения, расположенные за пределами усов диаграммы.

Однако такие значения не обязательно являются ошибками: они могут отражать реальные особенности пациентов.

Поэтому удаление выбросов не выполняется автоматически. Перед обработкой необходимо проверить корректность значений и обосновать выбранный критерий.

### 6.6. Анализ категориальных признаков

Для категориальных переменных исследуются частоты отдельных категорий.

Для этого используются таблицы частот и столбчатые диаграммы.

Анализ позволяет:
- определить наиболее распространённые категории;
- выявить редкие категории;
- обнаружить возможный дисбаланс;
- оценить, требуется ли объединение категорий при дальнейшей обработке.

Особое внимание уделяется признакам `chest pain type`, `resting ecg`, `exercise angina` и `ST slope`.

### 6.7. Корреляционный анализ

Для числовых признаков рассчитывается корреляционная матрица и строится тепловая карта (heatmap).

Корреляционный анализ помогает определить, какие признаки имеют более выраженную линейную связь друг с другом.

Значения коэффициента корреляции находятся в диапазоне от -1 до 1:

- значение около 1 указывает на сильную положительную линейную связь;
- значение около -1 указывает на сильную отрицательную линейную связь;
- значение около 0 указывает на отсутствие выраженной линейной связи.

Корреляция не доказывает причинно-следственную связь между признаками.

Для наиболее интересных пар признаков дополнительно строятся диаграммы рассеяния (scatterplot).

### 6.8. Анализ целевой переменной

В датасете целевой переменной является `target`.

Анализируется количество объектов каждого класса и их соотношение.

Для этого используется таблица частот и столбчатая диаграмма.

Данный этап позволяет определить, насколько равномерно представлены классы.

Если обнаруживается существенный дисбаланс, при дальнейшем обучении модели потребуется учитывать его влияние на выбор метрик и методов обучения.

### 6.9. Исследование взаимосвязей признаков с целевой переменной

Дополнительно можно сравнить распределения числовых признаков для разных значений `target`.

Например, можно исследовать, различаются ли значения возраста, максимальной частоты сердечных сокращений или `oldpeak` между классами.

Для категориальных признаков можно сравнить частоты категорий в каждой группе.

Такие сравнения помогают сформировать предварительные предположения о потенциальной информативности признаков.

Полученные наблюдения не следует интерпретировать как медицинские выводы или доказательство причин возникновения заболевания.

## 7. Основные проблемы данных

В ходе анализа необходимо проверить наличие следующих потенциальных проблем:

1. **Пропущенные значения.** Определить, есть ли отсутствующие данные в отдельных столбцах.
2. **Потенциальные выбросы.** Проверить необычные значения числовых признаков с помощью статистик и boxplot.
3. **Различия в распределениях.** Выявить асимметрию и концентрацию значений в отдельных диапазонах.
4. **Редкие категории.** Определить категории с небольшим количеством наблюдений.
5. **Дисбаланс классов.** Проверить соотношение классов целевой переменной `target`.
6. **Корреляция между признаками.** Выявить признаки с выраженной взаимосвязью, которую следует учитывать при построении модели.
7. **Особенности кодирования.** Убедиться, что числовые коды категориальных признаков не интерпретируются как обычные измеряемые величины.

Фактическое наличие каждой проблемы подтверждается результатами анализа в `eda.ipynb`. Проблемы, которые не обнаружены, указываются как отсутствующие по результатам проверки.

Все преобразования должны обосновываться результатами анализа. Параметры обработки следует рассчитывать на обучающей выборке, чтобы избежать утечки данных.
